# UPLOAD STEPS — Beats (Walter's taps, like Muzzle, The Gatekeeper & the Diver)

Repo name: **Beats** (public, MIT — same as the others).

1. Create the repo (github.com → New repository → name `Beats` →
   Public → Create). Don't tick the README/gitignore boxes — ours
   come with the upload.
2. **About line** (the gear ⚙ next to About on the repo page): paste
   the line from ABOUT.txt.
3. **Upload the pack**: "uploading an existing file" → drag in
   everything from the `github-face` folder EXCEPT this steps file:
   README.md, ABOUT.txt, LICENSE, NOTICE.txt,
   beats-icon-512.png, beats-public-1.22.apk. Commit.
   (The APK rides in the repo upload too, AND in the release below —
   the release is the door people download from.)
4. **Release v1.22** "Beats — first public release": Releases →
   Draft a new release → tag `v1.22` → title
   `Beats 1.22 — first public release`. In the notes, say what's
   in it — the front of house and the Music Room core, the new
   open hat — and what's not (no Toy Cabinet, no Workbench, no
   MP3 export). In **Attach binaries** (NOT the notes box — the
   Muzzle lesson), attach `beats-public-1.22.apk`. Publish.

After it lands, Muse verifies the live page independently, like
the last four.
